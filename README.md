# ⚡ Milijon Multi-Protocol & Multi-Location Proxy Platform (v4.1)

یک پلتفرم جامع، آمادهٔ استقرار خودکار و تمام‌پایتون (100% Pure Python) بر پایهٔ FastAPI برای مدیریت پروکسی، تست زنده پینگ و توزیع ساب‌اسکریپشن‌های مولتی‌لوکیشن در پلتفرم ابری **Railway**.

---

## 🎯 قابلیت‌های کلیدی

- **موتور جمع‌آوری و تست زنده نودهای عمومی (Public Node Harvester & Health Check):** دریافت دوره‌ای نودهای معتبر گیت‌هاب، سنجش زنده هندشیک سوکت TCP و اندازه‌گیری پینگ دقیق، تفکیک کشور با پرچم واقعی و تزریق نودهای کم‌پینگ به سابسکریپشن‌ها به جای دامنه‌های ساختگی.
- **پشتیبانی از تمام پروتکل‌ها:** VLESS (Reality Vision & WebSocket), Trojan, VMess, Shadowsocks, WireGuard.
- **تولید ساب‌اسکریپشن چندفرمت:** Sing-box (v1.8+ JSON), Clash Meta (YAML), Base64, Plain URI, WireGuard (.conf).
- **مولتی‌لوکیشن و تفکیک کشورها:** آلمان (DE)، هلند (NL)، آمریکا (US)، فنلاند (FI)، ترکیه (TR)، انگلستان (GB)، فرانسه (FR)، سنگاپور (SG)، ژاپن (JP).
- **بهینه‌ساز شبکه ایران:** تزریق Clean IP چرخشی، تنظیم MTU 1400، فرگمنت TLS و روتینگ دایرکت ایران.
- **داشبورد فارسی PWA:** پنل مدیریت واکنش‌گرا با فونت وزیرمتن، مدیریت نودها، تست پینگ زنده و مدیریت کاربران بدون خطای سرور.

```
milijon/
├── Dockerfile                      # ایمیج سبک پایتون ۳.۱۱
├── railway.json                    # پیکربندی استقرار Zero-Config در Railway
├── requirements.txt                # نیازمندی‌های پایتون پروژه
├── main.py                         # هسته وب‌سرور FastAPI و روت‌های پنل
├── Procfile                        # فرمان استارت سرور
├── start.sh                        # اسکریپت ران‌تایم و اجرای uvicorn
├── docker-compose.yml              # اجرای کانتینری محلی
├── .dockerignore                   # فیلتر فایل‌های بیلد
├── README.md                       # مستندات راهنما
├── .github/
│   └── workflows/
│       └── railway.yml             # پایپ‌لاین CI/CD گیت‌هاب به ریلوی
└── app/
    ├── __init__.py                 # پکیج ران‌تایم
    ├── config.py                   # تنظیمات سرور، سورس‌های گیت‌هاب و پارامترها
    ├── database.py                 # مدیریت ایمن SQLite با Timeout و ژورنال
    ├── harvester.py                # موتور جمع‌آوری و تست زنده پینگ نودها
    ├── generator.py                # موتور توزیع و تولید سابسکریپشن‌ها
    ├── proxy_engine.py             # هندلر وب‌سوکت VLESS و Trojan
    ├── geo.py                      # ماژول تشخیص کشورها و پرچم‌های ایموجی
    ├── node_parser.py              # پارسر استاندارد لینک‌های پروکسی
    ├── proxy_formats.py            # جنراتور فرمت‌های Sing-box و Clash Meta
    └── templates/
        └── index.html              # داشبورد فارسی و رابط کاربری PWA
```

## 🚀 استقرار در ریلوی (Zero-Config)

کافیست تمام محتویات این پوشه را در مخزن گیت‌هاب خود قرار داده و به Railway متصل کنید:
1. پورت داینامیک `$PORT` به صورت خودکار Bind می‌شود.
2. دیتابیس SQLite بدون قفل شدن دیسک فعال می‌گردد.
3. تسک پس‌زمینه Harvester هر ۳۰ دقیقه نودهای معتبر را تست و به‌روزرسانی می‌کند.
